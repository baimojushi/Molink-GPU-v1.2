Purpose
-------
This archive contains the fix for the repeated "hanging too high" result.
It is not the untouched Molink-GPU-v1.1 baseline.

Key guarantees
--------------
1. A metric hanging rule remains the authoritative vertical target.
2. The max-empty-rectangle heuristic may search horizontally, but may not
   silently replace the vertical target selected by the metric rule.
3. A semantic rectangle is rejected for vertical fitting when it does not
   contain the requested target height.
4. Support context is associated with the current wall; counter support and
   a trusted floor fallback are handled explicitly.
5. Floor refinement, wall projection, and gravity-reference diagnostics have
   regression coverage.
